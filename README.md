### Portfolio (Multi‑Page) — Software Engineering Student

- Multi‑page personal portfolio for a Software Engineering student.
- Pages: `index.html`, `about.html`, `skills.html`, `projects.html`, `contact.html`, plus `projects/project-*.html` detail pages.
- Responsive layout with animations via ScrollReveal.
- Navigation highlights the current page.

How to use
- Open `index.html` in a browser. Navigate using the header.
- Replace placeholder text, social links, and project descriptions with your own.
- To add a new project page, copy one of the files in `projects/` and link it from `projects.html`.

Customize
- Update name/role in `index.html`.
- Change accent color by tweaking `--hue-color` in `assets/css/styles.css`.
- Swap images in `assets/img/`.
