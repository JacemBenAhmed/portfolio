Bureau d'Ordre Management

Document workflow for a bureau d'ordre

I built an application to manage client request documents for a bureau d'ordre — handling intake, categorization, and tracking of every request through a clear, monitored workflow. The admin and dashboard interfaces give staff a real-time view of document status and processing activity.

Document management Admin dashboard Workflow tracking Notifications

Upload & categorization

Documents are uploaded, categorized, and versioned so the team always works with the latest version.

Real-time dashboard

A live dashboard surfaces processing status and analytics to help allocate resources efficiently.

Admin panel

Role-based management of users and requests, keeping the workflow secure and organized.

Workflow notifications

Automated notifications keep stakeholders informed as requests move through the pipeline.

Key Features

  • Document upload and categorization system
  • Client request tracking and management
  • Admin panel with user role management
  • Real-time dashboard with analytics
  • Automated workflow notifications
  • Document version control and history

Technologies Used

.NET Core Vue.js SQL Server Azure Docker Git/GitHub

Project Impact

  • Streamlined document processing workflows, reducing processing time by 60%.
  • Improved client satisfaction through faster, more transparent handling.
  • Provided actionable insights via the admin dashboard for better resource allocation.
