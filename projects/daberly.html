Daberly E-commerce Platform

Modern e‑commerce platform with full options

I built Daberly to be fast, simple, and trustworthy. Shoppers can browse clean product pages, chat in real‑time when they have questions, and get timely announcements about drops and deals. Behind the scenes, an admin dashboard gives full control over products, users, orders, and promos. Everything ships via Docker and Nginx on a VPS, with GitHub Actions keeping deployments hands‑off.

E‑commerce Real‑time Chat Admin Dashboard CI/CD

What I did

  • Developed a modern and secure e‑commerce website for online shoe sales with real‑time chat and dynamic product announcements with videos.
  • Built a full admin dashboard to manage products, users, orders, and promotions end‑to‑end.
  • Deployed the full‑stack app on a VPS using Docker and Nginx with CI/CD via GitHub Actions.
  • Technologies Used: .NET Core, Vue.js, SignalR, PostgreSQL, Docker, Nginx, Git/GitHub, GitHub Actions.
