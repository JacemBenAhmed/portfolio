Testy DevSecOps Platform

Plateforme CI/CD pour la sécurisation des solutions Odoo

J'ai développé Testy, une plateforme web DevSecOps complète qui intègre un pipeline Jenkins CI/CD pour tester et analyser des solutions Odoo. Cette plateforme permet aux développeurs de sécuriser leurs modules Odoo en automatisant les tests de qualité et de sécurité du code. Les utilisateurs peuvent se connecter via GitHub, sélectionner leurs dépôts et lancer des analyses complètes en un clic.

DevSecOps CI/CD SAST DAST Odoo Docker

Fonctionnalités principales

  • Authentification GitHub permettant aux utilisateurs de se connecter et sélectionner leurs dépôts pour exécuter des tests automatisés.
  • Tests SAST avec SonarQube pour analyser la qualité du code et Snyk pour détecter les vulnérabilités.
  • Tests DAST avec OWASP ZAP pour identifier les failles de sécurité dans les applications en cours d'exécution.
  • Analyse des Dockerfiles et conteneurs pour identifier les vulnérabilités dans les images Docker.
  • Génération de rapports détaillés avec historique des évaluations par dépôt.
  • Technologies utilisées : Express.js, Vue.js, Jenkins, Git/GitHub, Odoo, PostgreSQL, SonarQube, OWASP ZAP, Docker.

Architecture de la solution

La plateforme Testy est construite sur une architecture moderne et évolutive :

  • Frontend : Interface utilisateur intuitive développée avec Vue.js, permettant une expérience fluide et réactive.
  • Backend : API RESTful développée avec Express.js, gérant l'authentification, les requêtes GitHub et la communication avec les services d'analyse.
  • CI/CD : Pipeline Jenkins orchestrant les différentes étapes d'analyse et de test.
  • Conteneurisation : Utilisation de Docker pour isoler les environnements Odoo et les outils d'analyse (SonarQube, OWASP ZAP).
  • Base de données : MongoDB pour stocker les résultats d'analyse, l'historique des tests et les informations utilisateur.

Cette architecture permet une grande flexibilité et facilite l'ajout de nouveaux outils d'analyse ou fonctionnalités à la plateforme.
